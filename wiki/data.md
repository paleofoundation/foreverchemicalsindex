# Data and downloads

The dataset lists source-reported values from reviewed sources, as printed, with basis and page. Non-detects are censored results, not measured zeros. Values held for review are not included.

Generated records retain source, product, analyte, measurement basis, units, and source location. Download formats use the same reviewed records as the public tables.
