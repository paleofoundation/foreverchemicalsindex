# Analytes

These pages name individual PFAS, classes, and aggregate fluorine measures. A class page is not a measurement of one chemical. An aggregate fluorine result is not a concentration of one PFAS.

Pages with quoted values repeat numbers from the cited studies. Pages with empty sections have no measurement on file. That gap is not a measured zero. CAS identifiers that were not verified stay blank.
