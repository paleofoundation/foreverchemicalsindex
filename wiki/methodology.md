# Methodology

A category or analyte page may quote a value only when that value was transcribed from a filed source in this repository. The quotation keeps the printed unit, basis, and source location. The index does not convert units, fill blank cells, or treat a non-detect as zero.

The structured findings download is a stricter file. A row enters that file only when scope, matrix, result status, and review metadata meet the review gate. Until then, the row can appear as a quotation on a page and still be absent from the download. That absence is a gap in the file.

A source page needs a title, authors, year, publication, access URL, and either a DOI or an explicit `no_doi_assigned` declaration, plus `review_state: approved_for_public`. A DOI alone does not put a number into the structured file.

Aggregate fluorine measurements are not individual PFAS concentrations. Regulatory limits are not published here until the primary instrument and its scope are on file. No regulatory instrument is on file yet.
