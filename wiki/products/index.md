# Products

These pages cover foods, water, packaging, and consumer goods. The repository has not split foods into a separate ingredient list, so a food that was filed as a category stays on that category page.

A page marked with quoted values repeats numbers from the cited studies. A page with empty sections has no measurement on file. That gap is not a measured zero.
